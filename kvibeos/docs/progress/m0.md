# M0 — Toolchain, Limine, harness self-test

## Summary
Kernel boots via Limine v11.4.1 under SeaBIOS and OVMF, prints on COM1, and enters gated test mode
(CPUID hypervisor bit + fw_cfg "QEMU" signature + `opt/kvibe/test`). It exits QEMU via isa-debug-exit.
The harness verdicts are proven for pass, fail, panic, hang, triple fault and no-test-mode. Built by the reviewer.

## Decisions
- `limine` crate pinned `=0.5.0`: 0.6.x needs nightly Rust (`#![feature(ptr_metadata)]`).
- Limine v11.4.1 by commit: v12 has no prebuilt `-binary` branch.
- Test loop boots SeaBIOS (0.4 s to result under TCG); OVMF takes 3.3 s, so it gets its own tier.
- Two ISOs: `kvibeos.iso` (release, 2 s boot menu with normal/safe/verbose) and `kvibeos-test.iso` (no menu).
- QEMU 8.2 logs `Triple fault` under `-d cpu_reset`; the classifier keys on it.
- COM1 presence is probed via loopback and writes are bounded, so machines without a UART don't hang.

## Known issues
- No KVM in the reviewer's environment: perf budgets will SKIP locally until CI (KVM) runs them.
- `core.hooksPath` is set in the parent (retirement-mcp) repo while KVibeOS lives in a subfolder.
